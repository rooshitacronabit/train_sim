# 🚂 **Train Simulator**

A **Train Simulator** built with **Vite**, **React**, **TypeScript**, and **Three.js Fiber**.

## 📦 **Installation**

1. **Clone the repository:**
   ```bash
   git clone https://github.com/faizalCronabit/Sunr_train.git
   cd Sunr_train
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

## 🚀 **Run the Application**

Start the development server:
```bash
npm start
```

Open the application in your browser at: [http://localhost:5173](http://localhost:5173)

## 🛠️ **Build the Application**

To create a production-ready build:
```bash
npm run build
```

The build files will be generated in the `dist/` folder.

## 📚 **Technologies Used**
- **Vite** - Build tool for faster development.
- **React** - JavaScript library for building user interfaces.
- **TypeScript** - Strongly-typed JavaScript.
- **Three.js Fiber** - React renderer for Three.js.


**Enjoy building and simulating! 🚀🚂**
